# Software Construction Lab

Labs 1 and 2 for the Software Construction Practice course.

The Android project `AircraftWar2026` migrates a Java aircraft shooting game from Windows to Android. It includes SurfaceView rendering, touch control, automatic shooting, collision scoring, supplies, and pause/resume support.

Open the project in Android Studio from a path containing no Chinese characters. Android 11 (API 30) or later is required.

Build the debug APK and run Android Lint:

```powershell
.\gradlew.bat assembleDebug lintDebug
```

See [README.md](README.md) for the Chinese project description and lab documents.
