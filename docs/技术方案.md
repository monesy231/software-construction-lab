### 1.2 核心架构原则：**“换壳不换核”**

Windows 端源码 `WindowsAircraftWar` 共计 **53 个 Java 源码文件**，已经完整实现了**单例模式、简单工厂、工厂方法、策略模式、观察者模式、模板模式、DAO 模式**。跨平台迁移**不是重写游戏**，而是严格遵循以下原则：

1. **业务内核 100% 保留**：所有飞机、子弹、道具、生成工厂、弹道策略、观察者事件、难度模板逻辑均属纯 Java 计算，不依赖任何桌面 GUI 库，直接复制即可运行。
2. **仅替换 3 层平台外壳**：
   - **图片加载层**：`ImageIO.read(...)`（Swing/AWT） $\rightarrow$ `BitmapFactory.decodeResource(...)`（Android）
   - **渲染与循环层**：`JPanel` + `java.util.Timer` + `Graphics` $\rightarrow$ `SurfaceView` + `Runnable` 子线程 + `Canvas`
   - **输入交互层**：`MouseAdapter`（鼠标拖拽） $\rightarrow$ `View.OnTouchListener`（触屏 `MotionEvent`）
3. **分阶段解耦**：实验二暂不强行接入音效（`MusicManager` 先留空壳）和 UI 页面（`MainActivity` 直接加载 `EasyGame`），确保核心游戏循环一次性跑通后再逐步挂载外围功能。

### Step 3：参考 `SurfaceViewDemo` 重构 `Game` 渲染循环（Git Commit #3）

结合课程提供的 `SurfaceViewDemo/MySurfaceView.java` 与 `实验2.pdf` 第 20 页结构，将 `Game.java` 从 `JPanel` 改为 `SurfaceView`：

1. **改造要点**：
   - 类声明：`public abstract class Game extends SurfaceView implements SurfaceHolder.Callback, Runnable`
   - 核心字段：
     ```java
     private final SurfaceHolder mSurfaceHolder;
     private final Paint mPaint = new Paint();
     private volatile boolean mbLoop = false;
     private Thread gameThread;
     ```
   - 构造方法：`public Game(Context context, GameDifficulty difficulty)`
     - 调用 `super(context);`
     - 调用 `ImageManager.initImage(context.getApplicationContext(), difficulty);`
     - 初始化 `heroAircraft`（`resetState()`）、各链表、`new HeroController(this, heroAircraft)`
     - 初始化 `mSurfaceHolder = this.getHolder(); mSurfaceHolder.addCallback(this); setFocusable(true);`
   - `surfaceCreated`：
     - `ImageManager.initImage(getContext(), difficulty);`
     - `if (!started) { initDifficultyConfig(); started = true; }`
   - `surfaceChanged(holder, format, width, height)`：
     - 先 `stopLoop()`，记录旧宽高后更新 `Main.WINDOW_WIDTH = width; Main.WINDOW_HEIGHT = height;`；
     - 重新加载并缩放背景图；首次初始化位置，若后续尺寸改变则按新旧宽高比例换算英雄机坐标并按半宽半高夹紧；
     - 置 `surfaceReady = true; startLoopIfReady();`。
   - `surfaceDestroyed`：
     - 置 `surfaceReady = false;` 并 `stopLoop()`（`mbLoop = false;` + `interrupt()` + `join()` 等待线程结束）。
   - `resumeGame()` / `pauseGame()`（供 `MainActivity.onResume()` / `onPause()` 调用）：
     - 以 `surfaceReady && activityResumed` 双门控管理 `GameThread`，确保锁屏、切后台时即使 Surface 未销毁也能立刻停止线程。
   - `draw()` 方法（替换原 `paint(Graphics g)`）：
     ```java
     private void draw() {
         Canvas canvas = mSurfaceHolder.lockCanvas();
         if (canvas == null) {
             return;
         }
         try {
             // 1. 滚动背景
             if (ImageManager.BACKGROUND_IMAGE != null) {
                 canvas.drawBitmap(ImageManager.BACKGROUND_IMAGE, 0, backGroundTop - Main.WINDOW_HEIGHT, null);
                 canvas.drawBitmap(ImageManager.BACKGROUND_IMAGE, 0, backGroundTop, null);
                 backGroundTop += 2;
                 if (backGroundTop >= Main.WINDOW_HEIGHT) {
                     backGroundTop = 0;
                 }
             }
             // 2. 子弹、敌机、道具
             paintImageWithPositionRevised(canvas, enemyBullets);
             paintImageWithPositionRevised(canvas, heroBullets);
             paintImageWithPositionRevised(canvas, enemyAircrafts);
             paintImageWithPositionRevised(canvas, supplies);
             // 3. 英雄机
             if (ImageManager.HERO_IMAGE != null) {
                 canvas.drawBitmap(
                         ImageManager.HERO_IMAGE,
                         heroAircraft.getLocationX() - ImageManager.HERO_IMAGE.getWidth() / 2f,
                         heroAircraft.getLocationY() - ImageManager.HERO_IMAGE.getHeight() / 2f,
                         null
                 );
             }
             // 4. 分数与生命值
             paintScoreAndLife(canvas);
         } finally {
             mSurfaceHolder.unlockCanvasAndPost(canvas);
         }
     }
     ```
     > **关键细节**：用 `try { ... } finally { mSurfaceHolder.unlockCanvasAndPost(canvas); }` 包裹绘图，保证即使发生异常也不会锁死画布。

   package edu.hitsz.application;

   import android.view.MotionEvent;
   import android.view.View;
   import edu.hitsz.aircraft.HeroAircraft;

   public class HeroController {
       private Game game;
       private HeroAircraft heroAircraft;

       public HeroController(Game game, HeroAircraft heroAircraft) {
           this.game = game;
           this.heroAircraft = heroAircraft;
           game.setOnTouchListener(new View.OnTouchListener() {
               @Override
               public boolean onTouch(View view, MotionEvent motionEvent) {
                   int action = motionEvent.getAction();
                   if (action == MotionEvent.ACTION_DOWN || action == MotionEvent.ACTION_MOVE) {
                       int x = (int) motionEvent.getX();
                       int y = (int) motionEvent.getY();
                       int halfW = heroAircraft.getWidth() / 2;
                       int halfH = heroAircraft.getHeight() / 2;
                       int clampedX = Math.max(halfW, Math.min(Math.max(halfW, Main.WINDOW_WIDTH - halfW), x));
                       int clampedY = Math.max(halfH, Math.min(Math.max(halfH, Main.WINDOW_HEIGHT - halfH), y));
                       heroAircraft.setLocation(clampedX, clampedY);
                       return true;
                   }
                   if (action == MotionEvent.ACTION_UP) {
                       view.performClick();
                       return true;
                   }
                   return false;
               }
           });
       }
   }
   ```

   @Override
   public void run() {
       while (mbLoop) {
           long startTime = System.currentTimeMillis();
           if (!gameOverHandled) {
               gameTimeTick++;
               spawnEnemyAction();
               shootAction();
               bulletsMoveAction();
               aircraftsMoveAction();
               suppliesMoveAction();
               crashCheckAction();
               increaseDifficultyIfNeeded();
               postProcessAction();
               checkResultAction();
           }
           draw();
           if (gameOverHandled) {
               mbLoop = false;
               break;
           }
           long costTime = System.currentTimeMillis() - startTime;
           long sleepTime = Math.max(5, timeInterval - costTime);
           try {
               Thread.sleep(sleepTime);
           } catch (InterruptedException e) {
               Thread.currentThread().interrupt();
               break;
           }
       }
   }
   ```

     - **技术思路**：子线程建立 `Socket` 连接轻量级转发服务器（或局域网房主 `ServerSocket`），游戏循环每 500ms 发送一行 `SCORE:<score>:<hp>`，接收线程解析后更新 `Game` 中的 `opponentScore` 与 `opponentHp` 变量供 `Canvas` 绘制。

### 5.1 针对本项目的 5 大避坑清单

| 坑点 | 报错/异常现象 | 本项目专属解法 |
| :--- | :--- | :--- |
| **1. 资源文件名含大写** | `R` 文件不生成，`Cannot resolve symbol R` | `elitePlus.png`、`elitePro.png`、`prop_bulletPlus.png` 必须改为全小写下划线命名，改完执行 `Build -> Clean Project`。 |
| **2. `HeroAircraft` 饿汉式 NPE** | 启动即闪退，`NullPointerException: Attempt to invoke Bitmap.getHeight() on a null object reference` | `HeroAircraft` 改为懒汉式单例，且必须在 `Game` 构造/初始化中先调用 `ImageManager.initImage(...)`。 |
| **3. 写死 512×768 像素** | 在真机/高分屏上飞机只在左上角一小块区域活动 | `Main.WINDOW_WIDTH/HEIGHT` 去掉 `final`，首次 `surfaceChanged` 初始化并夹紧英雄机；后续尺寸变化按新旧宽高比例换算并按半宽半高夹紧（保留生命与得分，不重置状态）。 |
| **4. 退出或锁屏后绘制线程没停** | 锁屏/退出后后台继续运行或日志刷屏，再次进入黑屏或闪退 | 由 `MainActivity`（`onResume`/`onPause`）与 `SurfaceHolder.Callback` 双门控管理线程，在 `pauseGame()` 与 `surfaceDestroyed()` 中中断并 `gameThread.join()` 等待线程结束，且 `lockCanvas` 与 `unlockCanvasAndPost` 成对放在 `try-finally` 中。 |
| **5. 子线程直接弹 Toast/跳页面** | `CalledFromWrongThreadException` 或引发 ANR | `SurfaceView.run()` 中严禁直接操作 View；实验二只在 `Canvas` 上画字或打 `Log`，实验三统一用 `Handler` 切回主线程。 |
